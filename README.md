# sound dah

Мемные звуки для SillyTavern: срабатывают на сообщения и действия (*в звёздочках*) персонажей.

## Установка
Папку `sound-dah` положить в
`SillyTavern/public/scripts/extensions/third-party/` (или `data/<user>/extensions/`) и перезапустить/обновить страницу.

## Свои мемные звуки (ru/en)
1. Положи mp3/ogg/wav в папку `sounds/`.
2. Запусти `node update-list.js` в папке расширения (список соберётся сам) или впиши имена вручную в `sounds/sounds.json`:
   ["bruh.mp3", "vot-tak-vot.mp3", "oh-no.ogg"]
3. Обнови страницу. Файлы смешиваются со встроенными синтезированными звуками.
Пользователь в интерфейсе звуки не выбирает — только громкость, шанс, паузу и вкл/выкл.
